HOW TO RUN IT (VS Code, macOS):

1. Unzip this file. You'll get a folder called
   "AZIIKI_v1.4_BASIC_VERSION_1.0" — move it wherever you want to keep
   working from (e.g., your Desktop, or replace your old project folder).

2. Open VS Code -> File -> Open Folder -> select that unzipped folder.
   (Or from Terminal: `code AZIIKI_v1.4_BASIC_VERSION_1.0`)

3. Open the integrated terminal in VS Code (Ctrl+` / Cmd+`) and run:
     npm install
   (node_modules was deliberately left out of this zip — it's huge and
   platform-specific. This step rebuilds it correctly for your Mac.)

4. Still in that terminal, run:
     npm run dev

5. Open the URL it prints (e.g. http://localhost:3000) in your browser.
